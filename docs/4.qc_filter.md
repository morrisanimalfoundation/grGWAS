
Careful QC of genotyping data is an important step towards a successful GWAS.  Samples and/or variants that do not meet quality expectations need to be excluded.

>  *Note:* Typically, screening and excluding 1st degree relatives is the first step. However, this step will be postponed until the target cases and controls have been defined.  

## 4.1. Data exploration

Plink2 commands are used to assess heterozygosity, missing genotyping, allele frequency and Hardy-Weinberg equilibrium (HWE). The output are the files ending in ".het", ".smiss (Per-sample)/.vmiss (per-variant)", ".afreq" and ".hardy".

```
mkdir -p inspect
plink2 --bfile AxiomGT1v2.comp_merge.deDup.sexConfirm.public_ids --chr-set 38 no-xy --allow-extra-chr \
      --het --missing --freq --hardy 'midp'  \
      --output-chr 'chrM' --out inspect/AxiomGT1v2.explore

# There are currently:
# 913984 variants loaded from .bim file.
# 3224 samples (1609 males, 1615 females) loaded from .fam.
```

>  *Note:* The 'midp' modifier of the command `--hardy` applies the mid-p adjustment described [here](https://www.ncbi.nlm.nih.gov/pubmed/23934608). The mid-p adjustment tends to bring the null rejection rate in line with the nominal p-value and reduces the filter's tendency to favor retention of variants with missing data.

## 4.1.1. Extreme cases of heterozygosity

The [heterozygosity report](https://www.cog-genomics.org/plink/2.0/formats#het) of Plink compares the expected and observed number of homozygotes. Column #6 in the report is an estimate for their divergence. Postive estimates indicate high homozygosity while negative estimates indicate low homozygosity.

```
awk -v size=0.02 'BEGIN{OFS="\t";bmin=bmax=0}{ b=int($6/size); a[b]++; bmax=b>bmax?b:bmax; bmin=b<bmin?b:bmin } END { for(i=bmin;i<=bmax;++i){if(i==0) print -1*size,size,a[i]/1;else if(i<0) print (i-1)*size,i*size,a[i]/1;else print i*size,(i+1)*size,a[i]/1 }}'  <(tail -n+2 inspect/AxiomGT1v2.explore.het) > inspect/AxiomGT1v2.explore.het.histo 

tail -n+2 inspect/AxiomGT1v2.explore.het | awk '{sum += $6; sumsq += ($6)^2} 
          END { ave = sum/NR; sd = sqrt((sumsq-sum^2/NR)/NR); sd3_cutoff = ave - 3 * sd; print ave, sd, sd3_cutoff}'

sd3_cutoff="-0.208405"
cat inspect/AxiomGT1v2.explore.het | awk -v sdCut=$sd3_cutoff '{if(NR==1)print}{if($6<sdCut)print}' >  inspect/AxiomGT1v2.explore.het.lowHomo ## low homozygosity
```
High heterozygosity may indicate sample contamination, however high homozygosity might just indicate higher inbreeding.


## 4.1.2. Markers with significant deviation from HWE

The [Hardy-Weinberg equilibrium report](https://www.cog-genomics.org/plink/1.9/formats#hwe) reports the results of an exact test comparing the expected and observed heterozygote frequency of each variant. Column #9 in the report is the Hardy-Weinberg equilibrium exact test p-value.

```
awk 'BEGIN{OFS="\t";}{ if($10<1e-50)a["1e-50 or less"]++;
                       else if($10<1e-40)a["1e-40:1e-50"]++; else if($10<1e-30)a["1e-30:1e-40"]++; \
                       else if($10<1e-20)a["1e-20:1e-30"]++; else if($10<1e-10)a["1e-10:1e-20"]++; \
                       else if($10<1e-9)a["1e-9:1e-10"]++; else if($10<1e-8)a["1e-8:1e-9"]++; \
                       else if($10<1e-7)a["1e-7:1e-8"]++; else if($10<1e-6)a["1e-6:1e-7"]++; \
                       else if($10<1e-5)a["1e-5:1e-6"]++; else if($10<1e-4)a["1e-4:1e-5"]++; \
                       else if($10<0.001)a["1e-3:1e-4"]++; else if($10<0.01)a["1e-2:1e-3"]++; } \
                 END { for(i in a) print i,a[i] }'  <(tail -n+2 inspect/AxiomGT1v2.explore.hardy) | sort -g > inspect/AxiomGT1v2.explore.hardy.histo

## Use this to further explore variants with extreme deviation from HWE:
cat inspect/AxiomGT1v2.explore.hardy | awk '{if(NR==1)print}{if($10<1e-50)print}' >  inspect/AxiomGT1v2.explore.hardy.lowHWE

```
Serious genotyping errors often yield extreme p-values, therefore a cut-off like 1e-10 is usually advised to exclude these variants.
However,systematic genotyping errors are much more likely to show up as excess heterozygosity. Therefore, we use the 'keep-fewhet' mode, to filter out variants with excess heterozygosity only.


## 4.1.3. Genotype missingness in samples and variants

There are 2 missingness reports. One with the ".smiss" extension for [samples](https://www.cog-genomics.org/plink/2.0/formats#smiss) and another one with the ".vmiss" extension for [variants](https://www.cog-genomics.org/plink/2.0/formats#vmiss).  Columns #5 is the missing call rate in both files.

```
awk -v size=0.02 'BEGIN{OFS="\t";bmin=bmax=0}{ b=int($5/size); a[b]++; bmax=b>bmax?b:bmax; bmin=b<bmin?b:bmin } END { for(i=bmin;i<=bmax;++i) print i*size,(i+1)*size,a[i]/1 }'  <(tail -n+2 inspect/AxiomGT1v2.explore.smiss) > inspect/AxiomGT1v2.explore.smiss.histo

awk -v size=0.02 'BEGIN{OFS="\t";bmin=bmax=0}{ b=int($5/size); a[b]++; bmax=b>bmax?b:bmax; bmin=b<bmin?b:bmin } END { for(i=bmin;i<=bmax;++i) print i*size,(i+1)*size,a[i]/1 }'  <(tail -n+2 inspect/AxiomGT1v2.explore.vmiss) > inspect/AxiomGT1v2.explore.vmiss.histo
```
Missingness per individual shows 17 samples with about ~57% missing genotyping rates. These samples were genotyped on array A only. There is also one sample with ~43% missing genotyping rate. This sample was genotyped on array B only. While missingness per variant shows 36 extreme variants with about 50% genotyping rates.

## 4.2. Filter low quality samples and variants
```
tail -n+2 inspect/AxiomGT1v2.explore.het.lowHomo | awk '{print $1,$2}' > het_excess.lst
plink2 --bfile AxiomGT1v2.comp_merge.deDup.sexConfirm.public_ids --chr-set 38 no-xy --allow-extra-chr \
      --hwe 1e-10 'midp' 'keep-fewhet' --geno 0.05 --mind 0.05 --maf 0.01 \
      --remove het_excess.lst \
      --make-bed --output-chr 'chrM' --out AxiomGT1v2.filtered
```
* 913984 variants and 3224 samples loaded.
* 1 sample removed by (--remove).
* 18 samples removed due to missing genotype data (--mind).
* 36 variants removed due to missing genotype data (--geno).
* 2268 variants removed due to Hardy-Weinberg exact test (--hwe).
* 332754 variants removed due to minor allele threshold (--maf).

Now, there are 578926 variants and 3205 samples (1608 females and 1597 males) that passed filters and QC.
